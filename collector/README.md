# Vion Collector · by tomeeli

Отдельный сборщик метаданных релизов для Vion. Работает на Windows, NAS и VPS.
База хранится на вашем устройстве; регистрация в облаке Vion не требуется.

- [Проект Vion](https://github.com/den4m3/Vion)
- [Скачать выпуски](https://github.com/den4m3/Vion/releases)
- [Исходный код и актуальная инструкция](https://github.com/den4m3/Vion/tree/main/collector)

## Что делает

Собирает названия фильмов, год, дату публикации раздачи и доступные качества
1080p/2160p WEB-DL, BDRip и BDRemux. Один выбранный источник: Rutor напрямую
либо RuTracker, Kinozal, NNM-Club, seleZen через **ваш настроенный Jackett**.
Раздачи одного фильма объединяются; качества дополняются. Сериалы и CAM/TS
в эту ленту фильмов не входят. Дата публикации раздачи не означает дату
официальной цифровой премьеры. Новинки TMDB/ПоискКино в Vion остаются отдельными.

Загрузка выполняется в фоне раз в два часа, чтение готового каталога не ждёт
сети. Ошибка источника сохраняет предыдущую базу. Для каждого источника своя
база: переключение не удаляет остальные. Пустой ответ отмечается как ошибка,
а не как успешное обновление. Rutor: новая страница и постепенная догрузка
истории до 200 страниц; подтверждённая полнота истории не заявляется.

Начиная с **0.2.0**, сборщик также подбирает вертикальные обложки, скачивает
их на свой диск и отдаёт устройствам из локального кэша. При наличии TMDB/IMDb/
Кинопоиск ID используется точное сопоставление; иначе — совпадение названия и
года с единственным результатом. При неоднозначном совпадении обложка не подставляется.
По умолчанию включён подбор `auto`: TMDB, затем ПоискКино при наличии личных
ключей. Для Rutor дополнительно читается обложка из точной страницы раздачи,
но только с известных CDN изображений. Случайные кадры и картинки другого
фильма не используются. Поддерживаются JPEG, PNG и WebP.

Каталог читается независимо от фоновой очереди обложек: сетевые запросы не
выполняются при выдаче картинки клиенту. После перезапуска сборщик использует
сохранённые файлы. Размер кэша по умолчанию 512 МБ, при превышении удаляются
давно не использовавшиеся изображения; текстовая база и избранное не удаляются.
Ошибка или отсутствие обложки не удаляют карточку из базы.

Этот сборщик не является сервером полной синхронизации. Избранное и настройки
Vion в него не загружаются. Ключи каталогов задаются локально администратором
сборщика, не передаются клиентам и не включены в публичные архивы. Ссылки на
скачивание, magnet, torrent-файлы и видеопотоки не хранятся и не публикуются.

## Быстрый запуск — сборщик 0.3.0

Обычная настройка теперь выполняется в браузере: **выберите источник → вставьте ключи → «Сохранить и обновить»**. Редактировать JSON не нужно.

### Windows

1. Распакуйте весь Windows-архив в постоянную папку.
2. Откройте **Start-Collector.cmd → Быстрый запуск → Настроить в браузере**.
3. Вставьте скопированный ключ управления. Выберите источник и ключи для обложек, нажмите **Сохранить и обновить**.
4. В Vion выберите внешний сборщик, найдите его в домашней сети и вставьте **ключ подключения Vion** из мастера.

Python не нужен. Окно закрывается в трей; «Выход» останавливает сборщик. Необязательный `Install-Windows.ps1` создаёт ярлык на рабочем столе и запускает программу. Адрес, порт и дополнительные параметры остаются в отдельной вкладке. Пустые поля API-ключей сохраняют прежние значения.

### NAS

Понадобится один раз включить Docker / Container Manager средствами NAS. Распакуйте Server-архив в постоянную папку и выполните:

```sh
sh Install-NAS.sh
```

Скрипт проверит Docker Compose, соберёт и запустит контейнер, покажет ключ управления. Откройте `http://АДРЕС-NAS:8790/setup`, вставьте ключ и следуйте тому же мастеру. В Vion укажите адрес NAS и ключ подключения из мастера. Автопоиск доступен, если сеть контейнера пропускает mDNS; иначе вводится адрес NAS.

### VPS / Linux

Подготовьте сервер с Docker и Compose v2, распакуйте Server-архив и выполните:

```sh
sh Install-VPS.sh
```

Скрипт запустит контейнер **только на локальном адресе сервера**, покажет ключ управления и команду SSH-туннеля. После открытия туннеля на компьютере зайдите в `http://127.0.0.1:8790/setup`. Настройка источника и ключей — в браузере.

Для телевизоров вне сервера по-прежнему нужна ваша VPN или HTTPS reverse proxy. Первоначальная подготовка NAS/VPS требует доступа администратора; установка Docker, домена и VPN автоматически не выполняется. Для обновления используйте тот же скрипт из той же папки.

### Два ключа — разные права

- **Ключ управления** открывает мастер и меняет настройки. В Windows он копируется кнопкой быстрого запуска. Повторный просмотр — `Show-Setup-Key.cmd`.
- **Ключ подключения Vion** позволяет телевизору читать каталог. Его показывает мастер после входа; он не даёт права менять настройки сборщика.

Ключи не передаются в объявлениях поиска, не вставляются в URL и не сохраняются браузером мастера. Сохранённые ключи каталогов скрыты; пустое поле их не удаляет.

Повторно показать ключ управления Docker:

```sh
docker compose exec -T vion-collector python /app/collector.py --data /data --config /data/config.json --show-setup-key
```

Старые базы, ключи и кэш остаются на месте. Первый сбор и обложки требуют времени. Подробные параметры ниже нужны только для нестандартного подключения.

## Обновление и поиск в домашней сети

Windows: сохраняйте `config.json`, `windows-ui.json` и папку `data`. NAS/VPS: запускайте установочный скрипт из той же папки, не удаляйте именованный том и не используйте `down -v` без копии.

В Vion выберите «Подключение внешнего сборщика → Найти сборщик в локальной сети». Адрес подставится после выбора, ключ подключения вводится отдельно. В гостевой сети и Docker bridge поиск может не работать — тогда введите адрес NAS вручную. mDNS требует доступного UDP 5353; сборщик использует TCP 8790. Брандмауэр автоматически не изменяется.

Для Linux Docker доступна дополнительная `compose.discovery.yaml` с сетью хоста (нужен Compose 2.24+). На VPS используйте свой HTTPS/VPN. `--no-discovery` выключает локальные объявления. Ключи не передаются в объявлениях.

## Выбор источника

Настройки находятся в локальном `config.json` (для Docker — `/data/config.json`).
Обычные параметры меняйте в мастере /setup. Файл нужен только для дополнительных параметров; редактируйте его при остановленном сервисе.

```json
{
  "source": "rutracker",
  "interval_minutes": 120,
  "pages_per_update": 2,
  "jackett_url": "http://192.168.1.10:9117",
  "jackett_key": "ВАШ-КЛЮЧ-JACKETT",
  "indexer": "rutracker",
  "poster_provider": "auto",
  "tmdb_key": "",
  "poiskkino_key": "",
  "poster_width": 342,
  "poster_cache_mb": 512
}
```

`source`: `rutor`, `rutracker`, `kinozal`, `nnm-club`, `selezen` — строго один.
У Rutor можно указать `rutor_url` с HTTPS-зеркалом. У Jackett индексатор должен
быть добавлен, авторизован и успешно проходить Test. Его ID задаёт `indexer`.
Если сервис не поддерживает пустой запрос ленты, сборщик не придумывает
результаты и сохраняет предыдущий каталог с ошибкой обновления.
Вместо `jackett_key` можно задать переменную окружения `VION_JACKETT_KEY`.
При HTTP подключайте Jackett только в доверенной локальной сети/VPN; снаружи
используйте HTTPS. Ни конфигурация, ни ключ не включены в публичные архивы.

Период — 15–1440 минут. `pages_per_update` — 1–10 страниц Rutor за цикл;
при 1 обновляется только свежая страница, при 2+ догружается история.
Смена источника **в Vion** влияет на встроенный сборщик. Во внешнем режиме
источник выбирается **в мастере внешнего сборщика**, либо в его config.json.

## Подбор и хранение обложек

В `config.json`:

- `poster_provider`: `auto`, `tmdb`, `poiskkino` или `off`.
- `tmdb_key`: личный API key v3 либо API Read Access Token TMDB.
  Получение: [TMDB API](https://www.themoviedb.org/settings/api).
- `poiskkino_key`: личный ключ [ПоискКино](https://poiskkino.dev/).
- Вместо файловых ключей доступны переменные окружения `VION_TMDB_KEY` и
  `VION_POISKKINO_KEY`.
- `poster_width`: 185, 342 или 500 пикселей для TMDB. У остальных CDN сохраняется
  предоставленное исходное изображение; клиент Vion уменьшает его при показе.
- `poster_cache_mb`: 32–8192 МБ, по умолчанию 512.

После изменения конфигурации перезапустите сервис. Обложки собираются отдельной
фоновой очередью и будут появляться постепенно, а не все сразу. Клиент Vion
перепроверяет внешний каталог при повторном входе, если копия старше минуты;
для немедленного получения используйте «Обновить и проверить». Уже показанная
сетка не перестраивается от каждой полученной обложки.

Ссылки `/v1/images/ХЭШ-ПОДПИСЬ` отдают только сохранённое изображение. Подпись
ограничена конкретной картинкой; полный ключ подключения и ключи TMDB/ПоискКино
в URL не вставляются. Обладатель такой ссылки может прочитать эту картинку,
поэтому не публикуйте каталог своего сервера. Для VPS используйте HTTPS.
Поле `collectorPoster` передаёт относительный путь; новая сборка Vion привязывает
его к настроенному адресу сборщика. Старые версии Vion продолжают работать с
метаданными, но обложки сборщика им недоступны.

В этой версии сборщик хранит **вертикальные постеры каталога**. Горизонтальные
фоны, фирменные обложки и логотипы для каналов лаунчера пока подбираются Vion.

## Данные, резерв и проверка

В `data`: `access-key.txt`, независимые `releases-ИСТОЧНИК.json`, курсоры,
папка `posters` и `artwork-index.json`. Они входят в резервную копию.
Остановите сервис и скопируйте всю папку/том для резервной копии.
Ключ подключения даёт чтение каталога; интерфейса изменения по сети нет.
`--show-key` показывает его только по явному запросу; в обычном логе ключей нет.

```sh
python3 -m unittest discover -v
python3 collector.py --once
```

`GET /health` — только версия сервиса. `GET /v1/releases` — формат Vion schema=1,
заголовок `Authorization: Bearer КЛЮЧ`. До первой удачной загрузки возвращается
503; неправильный ключ — 401. Размер базы ограничен 8 MiB и 8000 карточками.
Никаких API для запуска произвольных команд или чтения файлов нет.

Тесты Windows и протокола выполняются отдельно. Наличие Dockerfile и systemd
юнита не означает, что проверена каждая модель NAS или конкретный VPS.

Источники данных: TMDB и ПоискКино при подключённых личных ключах.
This product uses the TMDB API but is not endorsed or certified by TMDB.
