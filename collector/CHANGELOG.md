# Изменения сборщика

## 0.2.1

- Если метаданные TMDB найдены, но его CDN не отдаёт картинку, режим auto пробует следующий источник.
- Некорректный формат локального artwork-index.json больше не останавливает очередь обложек; сохранённые файлы изображений остаются на диске.
- Запись без внешнего ID не объединяет два одноимённых фильма с противоречащими ID.
- Объединение большой базы использует индекс сопоставлений вместо попарного сравнения всех карточек.
- Совместимость формата каталога и существующих данных сохранена.

## 0.2.0

Подбор, постоянный кэш и выдача вертикальных обложек; TMDB/ПоискКино и изображения из точной страницы Rutor на поддерживаемых CDN. Отдельная очередь, ограничение объёма кэша и подписанные адреса изображений.
