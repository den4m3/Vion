Vion Collector 0.3.0 — быстрый запуск

WINDOWS
1. Распакуйте весь Windows-архив в постоянную папку.
2. Откройте Start-Collector.cmd → «Быстрый запуск» → «Настроить в браузере».
3. Вставьте скопированный ключ управления, выберите источник и введите ключи обложек.
4. Нажмите «Сохранить и обновить».
5. В Vion выберите внешний сборщик, найдите его в сети и вставьте ключ подключения из мастера.
Дополнительно Install-Windows.ps1 создаёт ярлык на рабочем столе и запускает окно.
Установка Python не нужна. При первом сетевом запросе разрешите доступ в частной домашней сети.
Закрытие окна оставляет сборщик в трее; «Выход» его останавливает.

NAS
1. Установите Docker / Container Manager средствами вашего NAS.
2. Распакуйте Server-архив в постоянную папку и один раз выполните: sh Install-NAS.sh
3. Откройте http://АДРЕС-NAS:8790/setup и введите ключ управления, показанный скриптом.
4. Выберите источник, вставьте ключи, нажмите «Сохранить и обновить».
5. В Vion подключите внешний сборщик по адресу NAS и ключу подключения из мастера.
Если mDNS проходит в вашей сети, можно использовать поиск; обычный Docker bridge может его не пропускать.
Команды нужны один раз для запуска контейнера; последующие настройки меняются в браузере.

VPS / LINUX
1. Подготовьте сервер с Docker и Compose v2. Распакуйте Server-архив.
2. Выполните: sh Install-VPS.sh
3. Скрипт покажет команду SSH-туннеля и ключ управления. Откройте туннель на компьютере,
   затем страницу http://127.0.0.1:8790/setup. Настройте источник и обложки в браузере.
4. Для подключения телевизоров настройте свой HTTPS reverse proxy или VPN.
Скрипт VPS оставляет порт доступным только на самом сервере, не открывает его всему интернету.
Для повторного запуска/обновления используйте тот же скрипт из той же папки.

ВАЖНО
Ключ управления и ключ подключения Vion — разные. Ни один не включён в публичный архив.
Пустое поле API-ключа сохраняет старое значение. Старые базы и кэш не удаляются.
Первый сбор и загрузка обложек требуют времени. Сохранённый каталог доступен независимо от очереди изображений.
Работа зависит от доступа к источникам. Для TMDB в вашей сети может потребоваться VPN.
Для RuTracker и других индексаторов заранее нужен настроенный Jackett.
Сборщик не заменяет полную синхронизацию избранного и настроек между Vion.
Ключ управления повторно: Windows — Show-Setup-Key.cmd; Docker — см. README.md.
