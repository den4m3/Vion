Optional DNS-SD discovery uses python-zeroconf (LGPL-2.1-or-later)
and ifaddr (MIT). Core collection still works if discovery is unavailable.
https://github.com/python-zeroconf/python-zeroconf
https://github.com/p-stieber/ifaddr
Install from requirements.txt. Dependency license texts are shipped in dependency-licenses/.
The standalone Windows executable bundles Python and standard-library components.

of bundled applications under their own license. Build tool, not an added
Python runtime dependency. License and source:
https://github.com/pyinstaller/pyinstaller/blob/develop/COPYING.txt
https://github.com/pyinstaller/pyinstaller

OpenSSL (Python SSL component): Apache License 2.0.
