# Метаданные каналов Vion

Применяются ко всем шести каналам: избранное, фильмы, новинки, релизы, сериалы,
мультфильмы. Также обновляются существующие записи Watch Next, принадлежащие Vion.

Стандартные поля `preview_program` / `watch_next_program`:

| Поле | Значение |
| --- | --- |
| `release_date` | Год фильма, например `2025`; не дата публикации раздачи |
| `canonical_genre` | Жанры из `TvContract.Programs.Genres`, через `Genres.encode` |
| `review_rating_style` | `2` — Android TV percentage |
| `review_rating` | Рейтинг 0–100: `73.0` соответствует исходному `7.3/10` |
| `short_description` | `2025 · драма, триллер · ★ 7.3` |
| `long_description` | Описание фильма, без потери исходного текста |

Не следует выводить `73.0` как оценку из десяти: для стиля 2 делите на 10,
либо показывайте значение как процент. Для обычного стиля Android stars=0
диапазон 0–5; Vion не помещает оценку 7.3 в это поле с неверной шкалой.

Точные русские названия жанров и исходная шкала дополнительно передаются
в UTF-8 JSON BLOB `internal_provider_data`:

```json
{
  "vion_metadata": {
    "version": 1,
    "year": "2025",
    "genres": ["драма", "триллер"],
    "rating": 7.3,
    "rating_scale": 10
  }
}
```

Остальные существующие JSON-поля сохраняются. Контракт `freehome_artwork`
для оригинального фона и логотипа названия не меняется. Неизвестные значения
года/рейтинга отсутствуют, а не заменяются нулём или выдуманными данными.

Отображение полей зависит от лаунчера. Vion публикует данные в системный
TvProvider; чтение нового `vion_metadata` требует поддержки со стороны лаунчера.
Стандартные поля доступны без этого расширения.

[Android TV PreviewPrograms](https://developer.android.com/reference/android/media/tv/TvContract.PreviewPrograms)
