# Vion
Personal Android TV movie browser and favorites manager.

Vion · by tomeeli

## Отдельный сборщик релизов

[Vion Collector для Windows, NAS и VPS — установка и настройка](collector/README.md)

[Скачать готовые архивы](https://github.com/den4m3/Vion/releases)

Метаданные и кэш вертикальных обложек хранятся на вашем компьютере/NAS/VPS. Vion получает каталог и обложки
по отдельному адресу и ключу; личные коллекции остаются в приложении.
Для подключения требуется сборка Vion с пунктом «Сборщик Windows / NAS / VPS».

[Поля для лаунчера: год, жанры, рейтинг](docs/launcher-metadata.md)
